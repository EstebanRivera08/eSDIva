# Geometry Functions

## Overview

The geometry utilities provide functions for:

- Coordinate system transforms (spherical ↔ Cartesian, transducer frame ↔ world frame)
- Computing distances, angles, and spatial relationships between transducer elements and field points
- Helper functions used internally by the transducer classes and brain atlas integration
